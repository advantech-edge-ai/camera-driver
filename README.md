# Camera Drivers

This repository is the download center for the camera driver auto-install script. All camera driver packages are stored here as GitHub Releases.

## Recommended: Use the Auto-Install Script

We recommend you install camera drivers using the camera driver auto-install script, not by downloading files manually.

The script can:

- Detect your MIC-AI board model automatically (for example: MIC-733AO, MIC-742)
- Detect your JetPack version automatically (for example: JetPack 6.2)
- Check the internal server first, then use this repository (GitHub) as a backup source
- Show a simple menu so you only need to select the camera **Vendor** and **Sensor**
- Download and install the correct driver package for your system

This is the easiest and safest way to install a camera driver. You do not need to choose the right file yourself.

> The auto-install script is not stored in this repository. If you need this script, please contact Technical Support.

## Manual Download (Optional)

If you need to download a camera driver manually, follow these steps:

1. Go to the [Releases](https://github.com/advantech-edge-ai/camera-driver/releases) page of this repository.
2. Search for your camera brand (for example: Otobrite, Sensing, Econ) in the release list.
3. Open the release for your camera and platform.
4. Read the PDF document included in the release. It has step-by-step installation instructions.
5. Download the driver package and follow the PDF to install it.

> Note: Manual installation is only for advanced users or special cases. Most users should use the auto-install script instead.
